# awsten jones

Static recreation of the Lotus Films site for awsten jones: Home, Gallery, About, and Contact.

Scraped Squarespace HTML is kept in `scraped/` for reference and is not linked from the site navigation. Videos play from the original public playlists with hls.js. Contact and about forms open a message to awstenjones@gmail.com.

GitHub Pages publishes this repository from `main` at `https://fractured-lotus.github.io/awstenjones.github.io/`.
